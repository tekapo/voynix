Voynix プライバシーポリシー

最終更新日: 2026年10月7日

Voynix は、Mac と Android 向けのローカルファーストな音楽プレーヤーで、個人（tekapo）が開発しています。このポリシーでは、Voynix アプリが扱うデータについて説明します。要点は、開発者があなたのデータを収集することはないという点です。アカウント、分析ツール、広告、開発者が運用するサーバーはありません。

端末に保存されるデータ

Voynix は、ライブラリ（音楽ファイルから読み取った曲の情報、プレイリスト、再生履歴、お気に入り、設定、アーティスト画像、アルバムのカバー）を、あなた自身の端末に保存します。Mac では ~/Library/Application Support/com.tekapo.voynix、Android ではアプリ専用の領域です。音楽ファイルは元の場所のまま読み取られ、どこにもアップロードされません。アプリを削除すると（Mac ではこのフォルダも削除すると）、これらのデータは消えます。

Wi-Fi 同期

Mac と Android をペアリングすると、同期の対象にした再生リスト、曲、再生履歴、お気に入りが、ローカルネットワークを通じて 2 台の端末の間で直接コピーされます。同期サーバーは Mac 上で動き、ペアリングが必要です。通信は、ペアリング時に固定した証明書で保護されます。このデータが開発者や第三者に送られることはありません。

外部サービスへの問い合わせ

一部の機能は、オンラインで情報を調べます。その場合、下の表の内容が各サービスに送られます。インターネットの通常の通信と同じく、サービス側にはあなたの IP アドレスも見えます。Voynix のアカウントや識別子は付きません。

サービス用途送られる内容
LRCLIB歌詞（Mac・Android）。歌詞の画面を開いたとき曲のアーティスト名、タイトル、アルバム名、再生時間
Deezerアーティスト画像とアルバムのカバー（Mac）アーティスト名、またはカバーを探すために入力した検索文字列
iTunes Search API（Apple）アルバムのカバー（Mac）アーティスト名とアルバム名、または入力した検索文字列

これらのサービスが受け取った問い合わせには、各サービス自身のプライバシーポリシーが適用されます。Voynix が、音楽ファイル、ライブラリ全体、再生履歴をこれらのサービスに送ることはありません。

Android の権限とカメラ

  • ネットワークへのアクセス（インターネット、ネットワークと Wi-Fi の状態、マルチキャスト）: Mac との同期、ネットワーク上の Mac の検出、上記の歌詞の検索
  • 通知、フォアグラウンドサービス（メディア再生、データ同期）、スリープ防止（ウェイクロック）: 再生の操作、画面オフ中の再生と同期の継続
  • QR コードでのペアリングは、Google Play 開発者サービスが提供する Google のコードスキャナを使います。Voynix が受け取るのは QR コードを読み取った文字列だけで、カメラの画像は受け取らず、保存もしません。

その他

  • Voynix は、クラッシュレポートや利用状況の統計を送信しません。
  • Voynix にはアカウントやサインインがなく、子どもから個人情報を意図して収集することはありません。
  • GitHub Releases や Homebrew からのダウンロードには、それぞれのサービスのポリシーが適用されます。

変更とお問い合わせ

このポリシーを変更するときは、更新日を変えて、このページに新しい内容を公開します。変更の履歴はリポジトリに残ります。ご質問は GitHub の Issue でお寄せください。脆弱性の報告は SECURITY.md を参照してください。
